## 2. 層級與呈現

| 層級 | 呈現方式 |
|---|---|
| 部／室／處 | 黃底（FFFF00），三格合併，字間加空格撐寬，例如「生　產　一　部」 |
| 課 | 淺色底，三格合併 |
| 工智處底下單位、金技課 | 淺青色（CCFFFF），合併 |

## 3. 誰會被列名

- 貼牆表 146 列（39 列標題、107 列有分機），EIP 檔共 175 筆。
- 只有 76 筆人員被列名；其餘 99 筆（現場班組與共用分機人員）合併成「單位名稱＋共用分機」一列。
- 列名對象：經理、副理、課長、組長、處長、特助等主管，以及有獨立分機的辦公室人員。
- 不列名的現場人員，以單位列代表。例如：製一組 211（4～5 人）、噴一課 (A棟) 511／(M棟) 512、品一課 (2F) 311／(4F) 312、金技課 161、皮技課 170／171、環保課 710、原料課 622、工智處一課 910、乾燥課／成品課 (H棟) 541／(J棟) 542。
- 同一單位有多支分機時，各列一列，用棟別或樓層區分。
- 另有非人員列：緊急專線 119、總機 613、e-learning、外勞宿舍、餐廳、2／3 樓機房、行動辦公室、會客室、禮堂、第三會議室、L棟無塵室、ALPHA ROOM、S棟、連續製程辦公室 262／263、守衛室。

## 4. 排序與分欄

- 最前面是不屬於任何部門的區塊：緊急專線 119、總機 613、廠長、副廠長。
- 每個部門內：主管 → 各課；課標題後先放課長，再放組或單位。
- e-learning、餐廳、禮堂、會議室等放在廠務部（總務課）底下。
- 分欄以最上層部門為單位，整塊放入同一欄，不拆到兩欄：
  - 左欄：管理單位、總經理室、廠長室（含生管課）、人事室、生產一部、生產三部、實驗工場、安衛室
  - 中欄：生產二部、品保部、技銷處（含五部）、環保部
  - 右欄：廠務部（含原料課）、環資管理處、工程管理暨智慧製造處
- 各欄長度不同（52、49、47 列），推測為廠務手動搭配以平衡欄高，並非嚴格依部門編號。

## 5. 等級（A／B）

- 欄頭稱「等級」，屬於分機號碼的屬性：104 支分機的 A／B 無任何衝突。
- EIP 檔沒有這個欄位。
- 表示該分機能否撥打外線（2026-11-08 確認）。

## 7. 對系統設計的影響

1. ~~每個部門加「列印方式」設定：列名（逐人）或只列單位。~~（已由需求文件 7.2 取代：誰列名依紀錄結構決定，不設部門層級的列印方式。）EIP 匯出列出所有「列入分機表」的人員與單位，不受「不列」影響。
2. 單位要有「列印用顯示名稱」，例如製一組、噴一課 (A棟)；多支共用分機要能對應到單位列。
3. 等級放在分機號碼上，同一支分機改一次，所有使用者跟著變。
4. 要有「不屬於任何部門」的頂端區塊，放緊急專線、總機、廠長、副廠長。
5. 分欄以最上層部門為單位，順序與分欄由廠務調整。
6. 相鄰的列使用同一支分機時，分機欄合併成一格、各列仍印名稱（貼牆表的製二組、製四組，已由廠務確認與製一組 211、製三組 221 共用）。
7. 列印版 1 改為對齊此原版：A4 直式、三組、黃底部門列、單位名稱／分機號碼／等級、檔尾撥號規則。目前範例的列印版 1（橫式、逐人列、欄名「線」）與原版不同。
